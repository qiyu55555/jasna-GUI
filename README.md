# jasna-GUI

## 项目简介

jasna-GUI 是一个为 [JASNA](https://github.com/Kruk2/jasna) 视频处理工具开发的图形用户界面（中文版），旨在简化 JASNA 的使用流程，提供更直观、更友好的操作体验。

JASNA 是一个强大的视频处理工具，主要用于视频去马赛克等高级视频处理任务。本GUI程序可以不与jasna.exe程序放在一起，放在任何位置都可以正常运行，只要jasna.exe的命令没有改变，则此程序可以适用于jasna的不同版本。

## 功能特点

- **直观的图形界面**：替代命令行操作，提供友好的可视化操作界面
- **完整的配置选项**：支持JASNA所有主要配置参数的设置
- **视频处理监控**：实时显示视频处理状态和进度
- **卡死监测机制**：自动检测视频处理过程中的卡死情况并进行处理
- **二次修复功能**：支持使用TVAI或Swin2SR进行二次修复
- **错误处理**：自动处理和分类处理成功/失败的视频文件
- **自定义编码参数**：支持详细的视频编码参数配置
- **智能转码**：当处理出错时自动进行智能转码

## 系统要求

- **操作系统**：Windows 10/11
- **硬件要求**：
  - CPU：至少4核心处理器
  - 内存：至少8GB RAM
  - GPU：NVIDIA显卡（推荐12GB以上显存）
  - 存储：至少10GB可用空间
- **软件依赖**：
  - Python 3.7+
  - Tkinter（Python标准库）
  - [JASNA主程序](https://github.com/Kruk2/jasna)（必须）
  - 可选：Topaz Video AI（TVAI）或Swin2SR（用于二次修复）

## 安装说明

### 方法1：直接运行（推荐）
1. 从[GitHub Releases](https://github.com/qiyu55555/jasna-GUI/releases)下载最新的可执行文件
2. 解压下载的文件到任意位置
3. 运行 `jasna-GUI.exe` 即可启动程序

### 方法2：从源码运行
1. 克隆本仓库：
   ```bash
   git clone https://github.com/qiyu55555/jasna-GUI.git
   ```
2. 确保已安装Python 3.7+
3. 直接运行 `jasna-GUI.py`：
   ```bash
   python jasna-GUI.py
   ```

## 使用教程

### 1. 基本设置

1. **JASNA程序地址**：指定JASNA主程序文件的完整路径
   - 示例：`D:/jasna-0.3/jasna.exe`
   - 注意：A卡不能用，N卡低于12G显存不建议使用

2. **切片帧数**：视频一次性处理的帧数
   - 建议值：30-90
   - 首次使用新数值需要编译模型，时间在0.2-4小时
   - 编译失败时请调小数值重新尝试

3. **输出视频后缀**：输出视频文件名的后缀
   - 示例：`-U` 表示输出文件名为：原文件名-U.mp4

4. **卡死几秒后跳过**：视频处理过程中卡死多少秒后自动跳过
   - 默认值：900秒（15分钟）

### 2. 文件夹设置

- **输入文件夹**：包含待处理视频文件的文件夹路径
- **输出文件夹**：处理后的视频文件将保存到此文件夹
- **成功视频存放文件夹**：处理成功后的原视频文件将被移动到此文件夹
- **出错视频存放文件夹**：处理失败的原视频文件将被移动到此文件夹

> **重要提示**：输入、输出、成功、出错文件夹最好不要为上下级目录或同一目录，否则可能会导致处理失败

### 3. 编码参数设置

- **自定义编码参数**：决定最后成品视频的质量和文件体积
  - 格式：`参数1=值1,参数2=值2,...`
  - 其中cq的值主要影响视频质量，cq值越小，视频质量越高，文件体积也越大
  - 默认值：`preset=P7,tuning_info=high_quality,rc=vbr,cq=31,aq=1,temporalaq=0,lookahead=32,gop=300`

- **卡死后转码参数**：用于处理出错视频的转码参数
  - 默认参数：`-preset p5 -tune hq -rc constqp -qp 15 -c:a aac -b:a 256k`
  - 建议qp值：14-16（值越低代表质量越高）

### 4. 二次修复设置

- **使用软件**：选择二次修复使用的软件
  - 无：不使用任何二次修复软件
  - TVAI：使用Topaz Video AI进行二次修复
  - Swin2SR：使用Swin2SR进行超分辨率修复

- **TVAI设置**：如果选择使用TVAI，需要设置TVAI程序路径和模型

- **Swin2SR设置**：如果选择使用Swin2SR，需要设置Swin2SR程序路径和模型

### 5. 开始处理

1. 完成所有必要的设置后，点击"扫描"按钮扫描输入文件夹中的视频文件
2. 扫描完成后，点击"开始"按钮开始处理视频
3. 处理过程中，可以在"正在处理视频"区域查看处理状态
4. 处理完成后，成功的视频会被移动到"成功视频存放文件夹"，失败的视频会被移动到"出错视频存放文件夹"

## 常见问题解答

### 1. 为什么程序启动后无法找到JASNA程序？
- 请确保正确设置了"JASNA程序地址"，指定JASNA主程序文件的完整路径
- 确保JASNA程序文件存在且可执行

### 2. 为什么视频处理过程中会卡死？
- 可能是由于视频文件过大或复杂
- 可能是由于GPU显存不足
- 请尝试调小"切片帧数"参数

### 3. 为什么处理后的视频质量不理想？
- 请尝试调整"自定义编码参数"中的cq值，cq值越小，视频质量越高
- 可以尝试使用二次修复功能

### 4. 为什么处理失败的视频没有被正确分类？
- 请确保输入、输出、成功、出错文件夹不是上下级目录或同一目录
- 检查文件夹权限是否正确

### 5. A卡用户可以使用吗？
- 不建议，JASNA主要针对NVIDIA显卡优化

### 6. 显存低于12G可以使用吗？
- 不建议，可能会导致处理过程中出现内存不足错误

## 注意事项

- **GPU要求**：本程序主要针对NVIDIA显卡优化，A卡用户可能无法使用
- **显存要求**：建议使用12G以上显存的显卡，否则可能会出现内存不足错误
- **文件夹设置**：输入、输出、成功、出错文件夹最好不要为上下级目录或同一目录
- **首次使用**：首次使用新的"切片帧数"值时，需要编译模型，可能需要较长时间
- **编码参数**：默认编码参数适用于大多数情况，不建议随意修改
- **二次修复**：使用TVAI或Swin2SR进行二次修复需要额外安装相应软件
- **性能优化**：处理大量视频时，建议分批处理，避免系统资源不足
