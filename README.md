适配https://github.com/Kruk2/jasna这个程序

理论上只要jasna的执行命令没有发生变化，此软件就适用于所有的jasna版本

已实现功能：

1、批量处理

2、卡死监测

3、编译模式（此模式可大幅度降低新手的上手难度。自动调整卡死监测阈值，编译后自动恢复原数值）

4、对输入文件根据处理情况进行分类

5、输出文件自定义后缀

6、自定义编码

7、正在处理视频的信息展示：名称、进度、分辨率、帧率、时长、已运行时间、预估剩余时间、破解速度、已处理帧数、未处理帧数、总帧数

8、已处理视频的用时倍率（破解用时/视频时长=用时倍率）

9、未处理视频列表显示视频的分辨率和时长

10、处理出错的视频显示出错位置（百分比表示）

11、中途手动停止或者卡死时自动清理临时文件

12、自定义切片帧数

13、处理情况总结：总视频数量、已处理数量、未处理数量、出错数量

14、队列所有视频处理完成后的动作：无、退出软件并休眠、退出软件并关机

15、选项提示说明（鼠标放上去0.5秒后显示）
